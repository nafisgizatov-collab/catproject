# ESP-посредник для событий двери

Плата на фотографии — ESP-01S в одноканальном релейном модуле и USB-программатор. Реле на распространённой версии платы управляется GPIO0, но у разных партий встречается обратная логика. Поэтому при первом включении к клеммам COM/NO/NC ничего не подключают: слышимый щелчок реле допустим, сетевое напряжение использовать не нужно.

## Что это решает

Яндекс Умный дом не даёт сценарию вызывать произвольный локальный URL. Цепочка строится через Home Assistant:

```
Датчик «Входная дверь» → сценарий Яндекса → переключатель ESPHome
→ ESP-01S → POST в TelegramCatDoor → обработка события двери
```

В Яндексе нужны две автоматизации: при открытии установить `Door event relay` во включено, при закрытии — выключено. Сам ESP появляется в Яндексе через интеграцию Home Assistant. Опрос Яндекс API остаётся резервным каналом, пока несколько реальных открытий и закрытий не будут сверены с журналом.

## Безопасный запуск

1. Установите Home Assistant и добавьте интеграцию ESPHome. Для публикации устройства в Яндекс используйте уже настроенную интеграцию Яндекс Умного дома Home Assistant.
2. Скопируйте `door-event-bridge.yaml` в конфигурацию ESPHome и создайте рядом `secrets.yaml` по образцу комментария вверху файла.
3. В `C:\telegram-cat\.env` задайте длинное случайное значение `CAT_DOOR_RELAY_TOKEN=...`. Такое же значение положите в `door_api_token` ESPHome.
4. В `C:\telegram-cat\config.ini` установите `CAT_DOOR_RELAY_API_ENABLED=true` и вместо `192.168.1.XXX` укажите постоянный адрес компьютера.
5. Подключите ESP-01S к USB-программатору, прошейте из ESPHome и проверьте, что переключатель меняет состояние. Первый тест выполняйте без проводов в COM/NO/NC.
6. После перезапуска задачи запись `runtime\door-event-ingress.log` должна содержать `accepted state=opened` и затем `accepted state=closed`.

API слушает только POST `/api/door-event`, принимает состояния `opened` и `closed`, требует заголовок `X-Door-Token` и не принимает тела больше 4 КБ. События сохраняются отдельно в `runtime\relay-door-event.json`; существующий опросчик Яндекса не перезаписывается.
